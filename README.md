### Ali Doğaner

Co-founder and CEO of [EVRE](https://evre.ai).

EVRE helps companies and individuals see how they communicate. It reads a conversation against clear behavior criteria and links each result to something that was said.

You can bring the transcript of a real conversation, or use EVRE from inside Claude or ChatGPT. You can also rehearse a performance review, a difficult customer call or an interview with an AI character and see it read against the same criteria.

Things I've published here:

- [tells](https://github.com/alidoganerr/tells): finds the habits that make text and code read as machine-written, in English and Turkish
- [yapay-zeka-turkcesi](https://github.com/alidoganerr/yapay-zeka-turkcesi): a Turkish guide to the same habits, with examples
- [transcript-kit](https://github.com/alidoganerr/transcript-kit): turns Zoom, Teams and WhatsApp transcripts into JSON and counts who talked how much
- [turkish-eval](https://github.com/alidoganerr/turkish-eval): Turkish prompts for testing language models, with rule-based checks
- [rubric-eval](https://github.com/alidoganerr/rubric-eval): weighted checklist scoring and rater agreement
- [conversation-scenario-spec](https://github.com/alidoganerr/conversation-scenario-spec): a JSON format for practice conversation scenarios
- [circuit-problems](https://github.com/alidoganerr/circuit-problems): circuit analysis problems with a solver that rechecks the answers
- [bughunt](https://github.com/alidoganerr/bughunt): Python debugging exercises with a grader
- [minicrm](https://github.com/alidoganerr/minicrm): a contact and follow-up tracker in one file
